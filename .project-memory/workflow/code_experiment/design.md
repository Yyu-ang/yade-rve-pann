# 方案设计与基线（code_experiment）

> 状态：复现路线与验收门槛已登记；算法实现和数值结果未开始
> 更新于：2026-10-05 15:34 +08:00

- **目标**：复现 Harazin et al. 的方法工作流，而非把 YADE DEM 的数值结果对标论文 FEM；先用解析 Neo-Hooke 算例验证 PANN+UQ，再扩展到 DEM-RVE。
- **研究问题**：能否用可验证的解析算例和 YADE DEM 周期 RVE，逐阶段实现域分离采样、PANN 与多态 UQ，并清楚界定每阶段的物理与数值证据？
- **假设**：不预设实现或复现成功。Example I 以解析参考解做定量验证；Example II 的 DEM-RVE 仅按收敛与定性趋势验收，不声称与论文 FEM 数值等价。
- **评估指标与协议**：按 `docs/reproduction_plan.md` 的计划执行并在运行前核实论文原文：Example I 的 PANN 应力相对 L2 误差目标 <5%，q99 相对误差目标 <1%；RVE 收敛 Δ = std(‖S‖)/mean(‖S‖) ≤0.5%；Example II 另检查体积分数增大时刚度/特征应力的定性趋势。记录数据规模、随机种子、软件版本、分割方式和误差定义。上述均是计划验收门槛，不是已取得的结果。

## 最小验证顺序

1. Example I：先核验解析 Neo-Hooke 应力、变量/单位约定与不确定性输入，再实现 PANN 应力和 UQ，并按计划指标验收。
2. Example II：核验 YADE 环境、周期边界及 `getStress()` 到第二类 Piola–Kirchhoff 应力的转换。
3. 对多个随机 RVE 检查 Δ ≤0.5%；通过后再扩展域分离采样、PANN 训练与多态 UQ。
4. 每阶段通过明确验收项后再进入下一阶段；报告中区分原论文方法、仓库适配和实测结果。

## 停止条件

- Example I 的解析应力或 PANN 微分实现未通过参考解检查时，暂停 UQ 扩展。
- 无法建立可复核的 `getStress()` 应力测度、单位和符号映射时，暂停 DEM-PANN 比较。
- RVE 收敛未达预设判据，或趋势对随机种子/边界处理高度敏感时，不宣称通过该阶段。
- DEM 与论文 FEM 的数值不对标；不得以流程相似替代物理等价证据。
