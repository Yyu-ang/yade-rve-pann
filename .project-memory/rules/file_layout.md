# 文件布局规则
> 冻结状态：已确认基础布局 2026-10-05；本次仅新增管理骨架，保留远端源码结构。

## 现有代码与研究资料布局

```text
rve/          RVE 生成、均匀化与收敛实现
sampling/     参数空间/力学空间采样
surrogate/    PANN 代理模型
uq/           不确定性量化
examples/     论文算例（按实际实现新增）
data/         生成数据；大体量派生数据默认不纳入 Git
docs/         论文方法笔记与复现说明
```

> `examples/` 与 `data/` 仅按需创建；README 中的目录说明不代表当前目录或脚本已存在。

## 管理结构

- 项目契约与用户看板放仓库根目录：`AGENTS.md`、`PROJECT_DASHBOARD.md`、`WORKLOG.md`。
- 唯一项目记忆根为 `.project-memory/`；本地技能副本为 `.skill/academic-project/`。
- `for_user/`、`for_worker/`、`for_manager/` 仅用于临时交付、WIP 和派单/复核；不作为正式研究结果长期目录。
- 并行代码任务在用户/派单授权后用独立分支和 worktree；`.worktrees/` 不放入过程目录。

## Git 与数据边界

- 本次初始化不移动或重命名远端已有源码/文档。
- 原始输入与可复现所需的小型文本配置可纳入版本管理；大型生成数据、缓存、日志默认忽略，并在 README/数据说明登记获取或生成方式。
- 禁止提交凭据、环境变量文件、个人配置和未审查的本地运行产物。
- 新建正式复现脚本时优先沿用既有 `rve/`、`sampling/`、`surrogate/`、`uq/` 模块；若确需新目录，先说明用途并更新本文件及文件注册表。
